# BookNest - Online Library System

React assignment built with Vite, React Router and Redux Toolkit.

## Requirements covered

- Home page with welcome message, categories and popular book cards
- Navigation: Home, Browse Books, Add Book
- Browse books by category using dynamic routes
- Search by title or author
- Dynamic book details page
- Add Book form with validation
- Redux state management for books
- Newly added book appears first after submission
- Custom 404 page showing the invalid URL without the Header
- Responsive CSS styling

## Run locally

1. Install Node.js.
2. Open this project folder in a terminal.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```
